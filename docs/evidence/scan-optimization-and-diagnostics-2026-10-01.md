# 검색 내부 최적화·실패 진단 — 2026-10-01

이 기록은 앞의 [설정 간소화·성능 측정](settings-and-performance-2026-10-01.md) 이후 작업이다. 기존 항목 8개에 PortManager가 추가된 **9개** 상태를 기준으로 했다. 앞의 8개 측정과 직접 비교하지 않는다.

## 구현 범위와 유지한 정책

- `MenuIconIndex`는 검색 시작 때 기존 아이콘의 ID 인덱스를 한 번 만든다. 이전 배열의 첫 일치 아이콘을 재사용하는 규칙과 새 항목의 캡처/앱 아이콘 fallback을 유지한다. 검색이 끝나면 인덱스를 해제한다. AX 요소나 좌표를 캐시하지 않는다.
- 화면 목록은 한 앱의 동기식 자식 항목 검색 안에서만 공유한다. 다음 앱으로 실행을 양보한 뒤에는 다시 읽는다. 수동 편집 완료 때 항목들의 화면 판정도 한 목록으로 수행한다.
- UI에서 사용하지 않는 `scanning`의 변경 발행을 제거하고, 접근성 허용 여부는 값이 바뀔 때만 발행한다. 항목 목록은 계속 새 AX 요소와 좌표로 갱신한다. 내용이 비슷하다는 이유로 이전 AX 요소를 유지하지 않는다.
- 250ms 위치 추적, 5초 검색 판단 타이머, 10~15초 강제 검색 정책, 이동 대기·연속 안정화 검사, 커서 보호·복귀·잠금 복구 정책은 유지했다.

## 제한된 실패 기록

정상 메뉴 클릭은 단계 기록을 메모리에만 남긴다. 기본 최대 32개이며 단계·아이콘 ID·상세 문자열도 바이트 수를 제한한다. 이벤트 전달, 이동 시작/검증, 원본 메뉴 관찰/닫힘, 복귀와 실패 단계를 경과 시간으로 구분한다. 클릭과 겹친 100ms 이상 앱 검색도 구분할 수 있다. 진단만을 위한 추가 AX 좌표 조회는 하지 않는다.

실패 때만 다음 파일 하나를 원자적으로 덮어쓴다. 저장 실패는 기존 오류 안내와 복귀 동작을 바꾸지 않는다.

```text
~/Library/Caches/dev.leneu.foldmenu/last-menu-failure.json
```

저장 내용은 아이콘 식별자, 숫자 창/PID·좌표, 단계 코드·경과 시간이다. 오류의 `localizedDescription`은 AX 메뉴 제목을 포함할 수 있으므로 저장하지 않는다. 실패는 `cancelled`/`operationFailed`로 구분하고, AX 오류 숫자는 발생 지점에서 기록한다. 실행 파일 경로 기반 ID는 `unidentified-item`으로 가린다. 스크린샷·창 제목·입력 내용은 수집하지 않고 외부로 전송하지 않는다. 캐시 파일이라 OS나 사용자가 삭제할 수 있으며 모든 실패 기록의 영구 보존을 보장하지 않는다.

`swift scripts/diagnose-fold-state.swift`는 기존 선택·원본 좌표와 함께, 파일이 있으면 마지막 실패의 최근 12단계를 읽기 전용으로 출력한다. 이 파일은 과거 기록이므로 현재 상태와 시각을 대조해야 한다. 성공한 클릭이 이전 실패를 지우지는 않는다. 기존 간헐 실패의 원인을 해결했다는 뜻은 아니다.

기록은 폴더에서 항목을 선택한 뒤의 메뉴 사용 동작에 한정된다. 폴더 패널 열기 이전 문제나 검사 도구의 버튼 탐색 INCOMPLETE는 이 파일의 기록 대상이 아니다. 실제 앱 실패를 고의로 유발하지 않았고, 저장·제한·개인정보 제외는 별도의 실제 파일 검사로 확인했다.

## 전후 유휴 측정
